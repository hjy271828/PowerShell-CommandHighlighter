# v0.1.1 - Hardening preview

This preview improves the Windows PowerShell 5.1 implementation while retaining
the pinned PSReadLine v2.4.5 baseline and existing editor behavior.

## Changes

- Preflight the complete shared patch plan before writing staged source; reject
  changed contexts, duplicate anchors, metadata drift and repeated injection.
- Preserve the previous complete build on compiler or payload failure.
- Keep affected command names neutral after pending alias/function/module/path
  changes while independently highlighting other commands.
- Invalidate discovery results when the module autoload preference changes;
  retain the measured 250 ms TTL and 512-name cache capacity.
- Validate installation ownership and paths, preserve extra/unrelated files,
  reject directory links, and test interrupted removal and rollback.
- Add a weekly experimental latest-tag/master compatibility probe with bounded
  network handling and diagnostic reuse. It never updates vendor or distributes
  unreviewed binaries.

## Versions and installation

Project version: 0.1.1. Patched module version: 2.4.5.2.
Upstream: PowerShell/PSReadLine v2.4.5 at
`98d5610f7210924b79f553d982e10a9bd64dd52f`.
This is an independent fork, not an official Microsoft release.

Download `PowerShell-CommandHighlighter-v0.1.1-windows-powershell5.1.zip` and
`SHA256SUMS.txt` from the same release. Follow the included README.
Installing adds 2.4.5.2 alongside the older version without editing profiles,
Oh My Posh or execution policies. Close sessions using the new build before
uninstalling it. Older versions are retained for rollback.

## Validation and remaining limitations

See `docs/hardening.md` and `docs/validation.md` in the source repository for the
review, exact test results, performance comparison and remaining limitations.
This remains a pre-release. PowerShell 7 deployment, all Vi modes and terminal
GUI details are unverified.

Discovery may auto-import modules and execute their initialization. Input
commands and dynamic expressions are not executed to determine colors.
Static environment tracking cannot predict arbitrary PowerShell side effects.
Cold discovery can exceed 20 ms. Upstream master/latest-tag probes are
experimental; only the pinned v2.4.5 baseline is supported.
