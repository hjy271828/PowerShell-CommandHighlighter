# v0.1.0 - Experimental preview

The first preview of real-time command existence coloring for Windows
PowerShell 5.1, inspired by zsh-syntax-highlighting.

## Included

- Green command names when discoverable in the current session; red when missing.
- AST-based handling of cmdlets, aliases, functions, module commands, external
  programs, explicit command paths, pipelines, and multiple statements.
- Existing PSReadLine editing, history, completion, multiline input, and inline
  history prediction paths.
- A prebuilt Windows package with demo, installation, removal, full component
  licenses, and pinned upstream provenance.

## Version identities

- Project/release: 0.1.0 / v0.1.0.
- Patched PSReadLine module: 2.4.5.1.
- Upstream base: PowerShell/PSReadLine v2.4.5,
  commit `98d5610f7210924b79f553d982e10a9bd64dd52f`.

This is a separately distributed PSReadLine fork, not an official Microsoft
release or a PowerShell Gallery publication under Microsoft's package name.

## Downloads and installation

Download `PowerShell-CommandHighlighter-v0.1.0-windows-powershell5.1.zip` and
`SHA256SUMS.txt`. GitHub's automatic source archives contain source code and
require building; the named ZIP contains the prebuilt module and scripts.

Extract the ZIP, open Windows PowerShell 5.1 in the extracted directory, and run
`install.ps1`. Follow the included README for checksum verification, reviewed
downloaded-file unblocking if needed, trying the demo, and uninstallation.
No SDK or administrator privileges are needed for the prebuilt package.

## Validation and limitations

The development platform was Windows 11 with Windows PowerShell 5.1.26100.9711.
Recorded validation includes 131 semantic/render checks and 16 real ConPTY
interaction checks per tested configuration. These are development results,
not a claim that every target environment or hosted CI run has passed.

PowerShell 7 deployment is unverified. Windows Terminal visual details,
clipboard integration, every Vi mode, and all window geometries are not fully
covered by the automated checks. Keep this release marked as a pre-release.

Only static command names are checked. Green does not guarantee successful
execution; arguments and runtime failures are outside the feature's scope.
Command discovery may auto-import modules and execute their initialization.
Cold discovery is synchronous and may exceed 20 ms; recorded cold-typing P95
was 20.708 ms, excluding terminal I/O and the rest of the renderer.

Existing profiles and module files are preserved by installation. A newer
upstream PSReadLine can take precedence and disable the custom coloring until
the fork is reviewed and rebased.
